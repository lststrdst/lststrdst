## 🧠 Чем занимаюсь

- строю Windows-инфраструктуру, GPO-развёртывание и endpoint automation;
- пишу агентов инвентаризации и защищённые gateway/relay-сервисы;
- собираю BI-платформы и data-пайплайны;

- люблю, когда security, observability и rollback заложены сразу, а не «потом».
